# 직접 테스트 가이드

실제 이동 대신 앉아서 테스트합니다. `다음 상황`은 연구 진행용 시뮬레이션 버튼이며, 일반 서비스 조작과 구분하여 안내합니다.

## 자동 테스트

`npm test` — 11개 테스트: 출근 복귀, 퇴근 복귀, 도보 재생 방지, 먼저 읽기 분기, 새로고침 복원, 다음 이동·초기화, 손상 저장값 복구, 두 활동의 위치 분리, 이전 페이지 이동 후 시작 위치 보존, 잘못된 경로 값 거부, 홈 복귀 시 위치 보존.

`npm run build` — 필수 배포 파일과 JS 구문 검사.

## 전체 흐름 직접 체험

| 테스트 | 조작 | 기대 결과 |
|---|---|---|
| 출근 시작 | 출근 → 이 책 이어읽기 | 도보 준비 화면. 본문을 읽도록 요구하지 않음 |
| 짧게 먼저 읽기 | 다음 상황 → 2분 먼저 읽기 → 다음 페이지 두 번 | 134p로 이동. 탑승해도 같은 페이지 유지 |
| 탑승 후 시작 | 초기화 후 승강장에서 탑승 후 이어읽기 → 다음 상황 → 이어읽기 | 대기 중 활동하지 않음. 탑승 후 저장 위치에서 시작 |
| 직접 저장 없이 환승 | 활동 중 다음 상황 → 환승 직전 → 환승 통로 | 134p 저장·중단. 이동 중 페이지 조작 요구 없음 |
| 핵심 복귀 | 다음 상황 → 두 번째 승강장 → 134p부터 이어읽기 | 추가 검색 없이 한 번 눌러 134p 본문으로 복귀 |
| 재탑승 | 다음 상황 → 두 번째 지하철 | 같은 페이지·활동 유지, 불필요한 안내 없음 |
| 새로고침 | 134p에서 새로고침 후 이어읽기 | 동일한 책·페이지, 일시정지 상태에서 복원 |
| 출근 종료 | 페이지를 더 넘기고 하차 | 실제 시작·종료 위치 표시, 다음 이동 버튼 |
| 다음 이동 | 다음 이동에서 이어읽기 → 탑승 후 이어읽기 | 직전 종료 위치 유지 |
| 퇴근 진입 | 퇴근 시나리오 → 알림 열고 이어가기 | 도보 준비, 00:42:18 기본 시청 위치 |
| SNS 이탈과 복귀 | 승강장 → SNS 열기 → 복귀 알림 받기 → 이어보기 | 원래 해리포터 활동과 이전 시간으로 이동 |
| 복귀 제안 거절 | 지금은 괜찮아요 | SNS 모의 화면 유지, 시청 위치 손실 없음 |
| 영상 중단·복귀 | 탑승 → 테스트 도구의 19분 진행 → 환승 → 두 번째 승강장 | 환승 시 타이머 정지. 저장된 정확한 시간 표시 |
| 영상 재개 | 이어보기 → 두 번째 지하철 | 저장 시간부터 증가. 00:00으로 돌아가지 않음 |
| 초기화 취소 | 테스트 초기화 → 취소 | 기존 위치·시나리오 유지 |
| 초기화 실행 | 테스트 초기화 → 초기화하기 | 출근 시작 화면, 132p / 00:42:18 기본값 |

퇴근 시청은 실제 영화가 없는 타이머 시뮬레이션입니다. 영상 몰입이나 스트리밍 품질은 검증하지 않습니다.

## 수용 기준

- 기능: 모든 중단·복귀에서 콘텐츠 ID와 페이지/시청 위치가 보존됨.
- 기능: RETURN POINT에서 한 번의 이어가기 선택으로 활동 화면에 복귀.
- 기능: 도보·환승에서 자동 중단, 새로고침 후 자동 재생 없음.
- 기능: 직접 저장 버튼을 누르지 않아도 위치를 기억함.
- 사용자: 참여자 80% 이상이 설명 없이 중단 지점에서 재개(PRD의 복귀 기준).
- 사용자: 참여자 80% 이상이 설명 없이 활동 시작, 선택부터 20초 이내(PRD).
- 사용자: 안내가 방해되지 않고 필요한 때 제공됐는지 인터뷰로 확인.
- 사용자: ‘활동이 끝났다’가 아니라 ‘잠시 멈췄다’고 느꼈는지 질문.

성공 여부, 복귀 소요 시간, 잘못 누른 횟수, 도움 요청, 저장 위치 인지 여부를 기록합니다. 아직 실제 사용자 연구를 수행한 것은 아닙니다.

## 검증 범위

자동 상태 테스트와 데스크톱 내장 브라우저의 모바일 뷰포트로 검증합니다. 실제 iPhone Safari·Android Chrome의 기기별 검수는 별도로 수행해야 합니다. 키보드 포커스, 320px 이상 화면의 가로 넘침, 작은 안내·복귀 버튼의 가독성도 함께 확인합니다.

## 이번 구현 검증 결과 (2026-10-12)

- 상태 회귀 테스트 11개 통과, 정적 배포 파일·JS 구문 검사 통과.
- 390px 모바일 뷰포트에서 출근 전체 흐름: 132→134p 독서, 환승 자동 저장, RETURN POINT의 134p 복귀, 새로고침 복원, 재탑승 후 135p 종료 확인.
- 같은 환경에서 퇴근 전체 흐름: 메시지→SNS→복귀 알림, 알림 거절·재제안, 42:18에서 시청 시작, 19분 건너뛰기 후 01:01:19 저장(실제 모의 재생 1초 포함), 같은 위치에서 복귀, 하차 기록 확인.
- 초기화 취소 시 유지와 초기화 실행 시 132p/42:18 복원 확인.
- 320px 시작 화면에서 문서 가로 넘침 없음. 390px에서 복귀 화면 시각 확인.
- 실제 휴대폰 기기 및 실제 참여자 사용성 평가는 미실시.
